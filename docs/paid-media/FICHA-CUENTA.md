# Ficha de cuenta — cómo se aterriza la pauta base

Los planes (`PLAN-LEAD-GEN.md`, `PLAN-ECOMMERCE.md`) son la **pauta base**: no cambian por cliente.
Lo que cambia es esta ficha. Se llena una vez por cuenta, vive en el grupo de ese cliente, y se
actualiza al cierre de cada mes.

Sin ficha, cualquier análisis mío parte de supuestos. Con ficha, la primera respuesta ya viene calibrada.

## Flujo de trabajo con los MCP de plataforma

Con Meta Ads MCP y Google Ads MCP conectados, el ciclo por cuenta es:

```
1. Leer la ficha (esta) para saber vertical, fase, guardarraíles y economía
2. Extraer de las cuentas los datos que pide el plan base para esa ventana (diaria/semanal/mensual)
3. Contrastar contra línea base y objetivo — no contra benchmarks externos
4. Nombrar el cuello de botella
5. Entregar propuestas en el formato P1/P2/P3 con ruta de aplicación
6. El usuario ejecuta y anota en la bitácora
7. Al cierre de mes: actualizar fase, línea base y guardarraíles de esta ficha
```

**Modo solo lectura**: la extracción es solo para analizar y presentar. Ningún cambio se ejecuta desde aquí.
