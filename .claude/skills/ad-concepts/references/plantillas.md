# Formato de entrega

## Pieza de Meta (video)

```
PIEZA #___ · ÁNGULO: ______ · OBJECIÓN: ______ · FORMATO: 9:16, ___ s

CONCEPTO: [una frase: qué ve el usuario y por qué le importa]

HOOK A: "..."          (0–3 s · qué se ve)
HOOK B: "..."
HOOK C: "..."

GUION (cuerpo común)
| Seg | Qué se ve | Qué se dice | Texto en pantalla |
|-----|-----------|-------------|-------------------|

CIERRE / CTA:
TEXTO PRINCIPAL: "..."            (___ car · los primeros 125 cargan el peso)
TÍTULO: "..."                     (___ car)
BOTÓN:
SUBTÍTULOS: sí
NECESITA PARA PRODUCIRSE:
SE JUZGA CON: hook rate → CTR → CPA/ROAS
```

## Pieza de Meta (estático o carrusel)

```
PIEZA #___ · ÁNGULO: ______ · FORMATO: 1:1 / 4:5 / carrusel ___ tarjetas
IDEA ÚNICA:
TEXTO EN LA PIEZA: [jerarquía: qué se lee primero, segundo, tercero]
(carrusel: contenido de cada tarjeta, la primera es el hook)
TEXTO PRINCIPAL / TÍTULO / BOTÓN + conteo
REFERENCIA VISUAL:
```

## Set de Google — RSA

```
GRUPO DE ANUNCIOS: ______ · INTENCIÓN QUE CUBRE: ______ · LANDING: ______

TÍTULOS (30)
| # | Título | car | Familia |
|---|--------|-----|---------|
(15 filas: coincidencia, beneficio, diferencial, prueba, CTA)

DESCRIPCIONES (90)
| # | Descripción | car | Función |
(4 filas: oferta, objeción, prueba, CTA + condición)

EXTENSIONES SUGERIDAS: sitelinks · textos destacados · fragmentos
FIJACIONES: solo si hay obligación legal o de marca, y se justifica
```

## Set de Google — PMax

```
GRUPO DE ASSETS: ______ · TEMA: ______
15 títulos · 1 título largo · 5 descripciones (una de 60) · conteos visibles
IMÁGENES: qué debe mostrar cada una, en 1.91:1 / 1:1 / 4:5
VIDEOS: concepto + guion, 16:9 y 9:16
TEMAS DE BÚSQUEDA SUGERIDOS (hasta 25):
```

## Cierre de toda entrega

```
APUESTA SEGURA: pieza #__ — por qué
EXPLORACIÓN: pieza #__ — qué hipótesis prueba
SI GANA EL ÁNGULO: qué se produce después (variantes de hook, otros formatos)
SUPUESTOS A VALIDAR: [DATO A CONFIRMAR] pendientes
NECESITAMOS DEL CLIENTE: qué y para cuándo
```
